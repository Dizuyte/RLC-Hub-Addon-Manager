RLC Hub+ v1.0 for RL Career Hub - by Milan
==========================================

An addon manager for RL Career Hub 0.2.0-beta.33 (Windows).
Your normal RL Career Hub is NOT modified: RLC Hub+ runs in its own copy of the game
(Documents\RL Career Hub+), with its own saves.

WHAT IT DOES
- Addons go in Documents\RL Career Hub+\addons (one folder per addon).
- When you create a new career, you pick its addons above the Start button.
  The list is locked: a save always keeps the addons it was created with.
  The Setup tab shows the addons of the loaded save.
- Saves imported from your normal game start with no addon.
- RLC Hub+ comes with no addon: addons are made by the community.
  Make your own: Documents\RL Career Hub+\Make an addon\ADDONS.md

INSTALL
1. Right-click the zip > "Extract All...". Do not run it from inside the zip.
2. Close RL Career Hub.
3. Double-click "Install RLC Hub+.bat".
   If Windows shows "Windows protected your PC": click "More info", then "Run anyway".
4. The installer finds your game. If it can't, paste the folder that contains
   "RL Career Hub.exe" and press Enter.
5. Press Y to import your current saves, settings and bots (recommended), or N to start
   fresh. Your normal saves are copied, never changed.
6. Wait while the game is copied (you need a few GB free), until it says "Done!".
7. Start it with the "RL Career Hub+" shortcut on your desktop. At the bottom of the
   Setup tab you should see "RLC Hub+ v1.0 by Milan".

UPDATE: run the new installer. Your RLC Hub+ saves and your addons folder are kept.

UNINSTALL: delete Documents\RL Career Hub+ and the "RL Career Hub+" shortcut.
