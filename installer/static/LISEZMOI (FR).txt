RLC Hub Addon Manager v1.1 pour RL Career Hub - par Milan
============================================

Un gestionnaire d'addons pour RL Career Hub 0.2.0-beta.35 (Windows).
Ton RL Career Hub normal n'est PAS modifie : RLC Hub Addon Manager tourne dans sa propre copie du jeu
(Documents\RLC Hub Addon Manager), avec ses propres saves.

CE QUE CA FAIT
- Les addons vont dans Documents\RLC Hub Addon Manager\addons (un dossier par addon).
- Quand tu crees une nouvelle carriere, tu choisis ses addons au-dessus du bouton Start.
  L'onglet Setup montre les addons de la save chargee. Tu peux les changer la, apres deux
  avertissements : changer les addons d'une carriere lancee peut casser la save.
  Si les addons viennent de personnes differentes, un avertissement te previent qu'ils
  pourraient ne pas marcher ensemble.
- Les saves importees du jeu normal commencent sans addon.
- RLC Hub Addon Manager est livre sans addon : les addons sont faits par la communaute.
  Cree le tien : Documents\RLC Hub Addon Manager\Make an addon (ADDONS.md et le LISEZMOI FR).

INSTALLATION
1. Clic droit sur le zip > "Extraire tout...". Ne le lance pas depuis le zip.
2. Ferme RL Career Hub.
3. Double-clique sur "Install RLC Hub Addon Manager.bat".
   Si Windows affiche "Windows a protege votre ordinateur" : clique sur "Informations
   complementaires", puis "Executer quand meme".
4. L'installateur trouve ton jeu. Sinon, colle le dossier qui contient
   "RL Career Hub.exe" et appuie sur Entree.
5. Appuie sur Y pour importer tes saves, reglages et bots actuels (conseille), ou N pour
   repartir de zero. Tes saves normales sont copiees, jamais modifiees.
6. Attends la copie du jeu (il faut quelques Go de libre), jusqu'a "Termine !".
7. Lance-le avec le raccourci "RLC Hub Addon Manager" sur ton bureau. En bas de l'onglet Setup
   tu dois voir "RLC Hub Addon Manager v1.1 par Milan".

MISE A JOUR : lance le nouvel installateur. Tes saves RLC Hub Addon Manager et ton dossier addons
sont conserves.

DESINSTALLER : supprime Documents\RLC Hub Addon Manager et le raccourci "RLC Hub Addon Manager".

RLC Hub Addon Manager n'est ni fait ni supporte par l'equipe de RL Career Hub. Les addons
appartiennent a leurs auteurs. Voir LICENSE.txt.
