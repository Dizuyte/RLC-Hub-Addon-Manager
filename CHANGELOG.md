# Changelog

## v1.1

- Works with RL Career Hub **0.2.0-beta.34** (the game's update). Run the new installer: it copies the updated game,
  your saves and addons stay.
- The Setup tab can change the addons of a save (with two warnings), and warns when the addons come from different
  authors.

## v1.0

- First version: copy of the game with its own saves (import from the normal game), addon manager, addon picker on
  the new-career screen (locked per save), addons of the save in the Setup tab, actions between the game window and
  the main process, log file `addons\_hubplus.log`, guide and hello-world example for addon makers.
